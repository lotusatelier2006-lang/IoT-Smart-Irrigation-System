# Danh sách thư viện sử dụng (Arduino IDE)

1. **Blynk** (Phiên bản `1.3.2`) - Giao tiếp IoT và điều khiển qua App điện thoại.
2. **DHT sensor library** by Adafruit (Phiên bản `1.4.6`) - Đọc dữ liệu cảm biến nhiệt độ, độ ẩm DHT11.
3. **Adafruit Unified Sensor** (Phiên bản `1.1.14`) - Thư viện lõi hỗ trợ cảm biến DHT.
4. **WiFi.h** (Tích hợp sẵn trong gói board `esp32` by Espressif Systems).
